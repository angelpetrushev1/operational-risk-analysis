Operational Risk and Loss Analysis

Project Overview

This project demonstrates the use of SQL to analyse operational risk events, financial losses, and outstanding cases using a fictional dataset.

Objectives

Analyse financial losses by risk category, date, and status.

Identify high-loss events requiring further investigation.

Monitor unresolved cases and outstanding financial exposure.

Perform basic data quality checks.

Prepare structured summaries to support reporting and decision-making.

Tools

SQL

Microsoft Excel

Power BI

SQL Skills Demonstrated

Data retrieval and filtering using SELECT and WHERE

Aggregation using SUM, COUNT, AVG, and MAX

Grouping and sorting using GROUP BY and ORDER BY

Conditional analysis using CASE WHEN

Subqueries and percentage calculations

Data quality checks for missing values and negative losses

Key Findings

6 sample operational risk events analysed.

Total recorded losses: 17,500.

Fraud represented the largest share of losses in the sample.

3 events remained unresolved, representing 11,000 in outstanding losses.

Conclusion

This project demonstrates foundational SQL skills in data analysis, financial loss monitoring, data quality validation, and structured reporting.

Note: The dataset is fictional and intended for learning purposes only.
